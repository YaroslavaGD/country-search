# DESIGN

Живой поиск стран по `https://countries.dev/name/{query}`. Задача проекта: не допустить гонку устаревших ответов, случаи когда медленный ответ на старый запрос перезаписывает на экране результат нового.

## Структура

- `src/core/` - логика без DOM, тестируется без браузера и без сети:
  - `debounce.ts` - задержка вызова;
  - `searchCountries.ts` - запрос, 404, `HttpError`, таймаут;
  - `classifyError.ts` - различает отмену, таймаут, ошибку сервера и сети;
  - `mapCountryResponse.ts` - преобразует ответ API в данные страны;
  - `searchController.ts` - связывает ввод, debounce, отмену и состояние экрана;
  - `errors.ts`, `types.ts` - `HttpError` и типы.
- `src/ui/` - отрисовка: `createElement.ts`, `renderCountryCard.ts`, `renderStatus.ts`, `createSearchView.ts`.
- `src/main.ts` - соединяет контроллер с отображением.
- `tests/` - тесты и фикстуры (`germany.json`, `antarctica.json`).

Контроллер не знает про DOM: он сообщает состояние через `onChange` (`idle`, `loading`, `success`, `empty`, `error`), `ui` только рисует.

## 1. Отмена устаревших запросов

1. `searchController.ts` создаёт отдельный `AbortController` для каждого запроса и передаёт его `signal` в `searchCountries()`.
2. При каждом изменении поля `input()` сразу отменяет предыдущий запрос через `abort()`. Отмена до `debounce`.
3. При пустом вводе состояние переключается в `idle`, а вызов debounced-функции сбрасывает предыдущий таймер.
4. В `searchCountries.ts` внешний сигнал объединяется с `AbortSignal.timeout()` через `AbortSignal.any()`. Таймаут по умолчанию - 10 секунд (`REQUEST_TIMEOUT_MS`).
5. `classifyError.ts` различает `AbortError`, `TimeoutError`, `HttpError` и сетевые ошибки. Отмена не отображается пользователю, остальные ошибки переводят приложение в состояние `error`.

`AbortController` выбран вместо флага актуальности, так как он прекращает сам запрос, а не просто игнорирует его результат. Это позволяет меньше нагружать сервер и не требует дополнительной проверки актуальности каждого ответа.

Тест на гонку использует мок `fetch`, он отслеживает `signal` и отклоняет промис с `AbortError` при отмене. Проверяется, что результат последнего запроса не перезаписывается устаревшим ответом.

## 2. Задержка debounce

Используется задержка **300 мс** (`DEBOUNCE_MS` в `main.ts`).

- Без `debounce` запрос отправлялся бы при каждом изменении строки, увеличивая сетевую нагрузку.

- При задержке 1–2 секунды поиск заметно терял бы отзывчивость.

- **300 мс** позволяют сократить количество запросов без сильной задержки интерфейса.

`debounce` отвечает за частоту отправки запросов, `AbortController` - за отмену устаревших. Поэтому отмена вызывается при вводе, не дожидаясь срабатывания `debounce`.

В `debounce.ts` идентификатор таймера хранится в замыкании. Каждый новый вызов сбрасывает предыдущий таймер и устанавливает новый. В результате функция вызывается с аргументами последнего вызова. Обёртка создаётся один раз при инициализации контроллера.

## 3. Сложность (Big O)

Обозначения: `L` - количество языков, `C` - количество валют, `n` — количество стран в ответе.

### `mapCountryResponse`

- Время: **O(L + C)** - каждый список обходится один раз, остальные поля копируются за O(1).).
- Память: **O(L + C)** - создаются новые массивы языков и валют..
- В реальных данных `L` и `C` ограничены небольшими числами (единицы), поэтому на практике обработка одной страны выполняется за константное время.
- Для всего ответа `searchCountries` вызывает функцию для каждой страны: **O(n x (L + C))**.

Кэширование и дедупликация запросов не реализованы.

## 4. Принципы чистого кода и где они применены

- **Single Responsibility** запросы, debounce, маппинг, классификация ошибок, управление состоянием и UI разделены по модулям. (`searchCountries.ts`, `mapCountryResponse.ts`, `debounce.ts`, `classifyError.ts`, `searchController.ts`, `src/ui/*`).
- **Separation of Concerns** `src/core/` не зависит от `DOM`, `src/ui/` отвечает только за отображение.
- **Pure Function** `mapCountryResponse` не имеет побочных эффектов и не изменяет исходный ответ API.
- **Строгие типы.** В `classifyError` аргумент имеет тип `unknown` и сужается через `instanceof`, без `any` и приведений типов. `SearchState` описан как размеченное объединение, и `renderStatus` обрабатывает все статусы через `switch`. Словарь `ERROR_MESSAGES` типизирован через `Record`, поэтому при добавлении нового вида ошибки компилятор покажет, что не хватает текста.
- **Strict Typing** `SearchState` описан размеченным объединением, ошибки принимаются как `unknown` и сужаются через `instanceof`. `ERROR_MESSAGES` типизирован через `Record`.
- **Error Handling** отдельно обрабатываются `404`, `AbortError`, `TimeoutError`, `HTTP`-ошибки и сетевые сбои.
- **DRY** Ссоздание `DOM`-элементов вынесено в `createElement.ts`, формирование списков - в общую функцию `renderList`.
- **KISS** детальная информация о стране реализована через нативный `<details>` без JavaScript.
- **DOM Safety** динамический контент добавляется через `textContent` и `createElement`. `innerHTML` и `insertAdjacentHTML` не используются.
- **TDD** тесты обязательной логики написаны до реализации. Сеть мокируется, время контролируется через fake timers.
